# 金聚源三类业务工作流

## 全局规则

### 销售端
- 1. 销售端：新建报单（开始）

### 系统
- 2. 系统读取当前指导价（自动）
- 3. 判断：成交价是否低于指导价？（判断）
- 7. 报单终止 / 状态：价格特批驳回（结束）
- 8. 报单状态：已激活（状态）
- 11. 系统记录：旧价 / 新价 / 修改人 / 生效时间（留痕）
- 12. 生效时间之后的新报单按新价判断（规则）
- 13. 生效时间之前的报单和合同价格快照不变（规则）

### 老板端
- 5. 老板端：价格特批审批（低价）
- 6. 判断：老板是否通过？（判断）
- 10. 老板端：维护指导价（设置）
- 14. 老板端：全过程查看报单、合同、付款、出库、对账、退车、利润（查看）

### 财务端
- 4. 财务端：确认报单（确认）

### 运营端
- 9. 运营端：发起合同审批（下一步）

## 卖车流程

### 销售端
- 1. 销售端：销售报单 / 新建报单（开始）
- 2. 选择车辆：在库车辆（录入）
- 3. 销售方式：整车销售（录入）
- 4. 填写客户、成交价、定金/首付款、收款信息（录入）

### 系统
- 5. 系统生成报单并锁定车辆（自动）
- 6. 判断：成交价低于指导价？（判断）
- 11. 报单状态：已激活（状态）
- 19. 合同状态：待出库（状态）
- 25. 车辆状态：已售，卖车流程结束（结束）

### 老板端
- 7. 老板端：审批中心 / 价格特批（低价）
- 8. 老板审批：通过或驳回（确认）
- 26. 老板端：查看全过程记录（查看）

### 财务端
- 9. 财务端：审批中心 / 报单确认（查看）
- 10. 财务点击：确认报单（确认）
- 14. 财务端：审批中心 / 合同审批（确认）
- 17. 财务端：审批中心 / 首次付款（查看）
- 18. 财务上传银行到账回单并点击通过（确认）
- 21. 财务端：确认合同和款项无误（确认）

### 运营端
- 12. 运营端：销售报单 / 转合同（点击）
- 13. 运营生成卖车合同（发起）
- 15. 运营端：发起首付款及押金支付流程（发起）
- 16. 运营上传客户付款截图（上传）
- 20. 运营端：发起车辆出库（发起）

### 车管端
- 22. 车管端：审批中心 / 车辆出库（查看）
- 23. 车管上传出库照片、出库单照片（上传）
- 24. 车管点击：确认出库（确认）

## 租车流程

### 销售端
- 1. 销售端：销售报单 / 新建报单（开始）
- 2. 选择车辆：在库车辆（录入）
- 3. 销售方式：经营租赁（录入）
- 4. 填写客户、租期、租金、押金、成交价/租赁总价（录入）
- 25. 租期结束：销售端车辆管理 / 发起退车（发起）

### 系统
- 5. 系统生成报单并锁定车辆（自动）
- 6. 判断：成交价低于指导价？（判断）
- 10. 报单状态：已激活（状态）
- 17. 合同状态：待出库（状态）
- 21. 车辆状态：租赁中（状态）
- 24. 该期账单状态：已还款；有未还期数则继续对账（循环）
- 31. 车辆状态：在库 / 二手车，租车流程结束（结束）

### 老板端
- 7. 老板端：审批中心 / 价格特批（低价）
- 29. 老板端：领导审批，如需退款确认（确认）

### 财务端
- 8. 财务端：审批中心 / 报单确认（查看）
- 9. 财务点击：确认报单（确认）
- 13. 财务端：审批中心 / 合同审批（确认）
- 16. 财务上传银行到账回单并点击通过（确认）
- 19. 财务端：确认合同和押金到账（确认）
- 23. 财务端：核对银行回单、流水号（核对）
- 28. 财务端：复核扣款、押金、退款金额、退款账户（复核）
- 30. 财务端：执行出款（出款）

### 运营端
- 11. 运营端：销售报单 / 转合同（点击）
- 12. 运营生成租赁合同（发起）
- 14. 运营端：发起押金支付流程（发起）
- 15. 运营上传客户付款截图（上传）
- 18. 运营端：发起车辆出库（发起）
- 22. 运营端：每期发起还款对账（发起）
- 27. 运营端：填写租金、违章、ETC、保养、事故等数据（填写）

### 车管端
- 20. 车管上传出库照片、出库单照片并确认出库（确认）
- 26. 车管端：退车验工，填写验车、工具、损伤、照片（填写）

## 以租代售流程

### 销售端
- 1. 销售端：销售报单 / 新建报单（开始）
- 2. 选择车辆：在库车辆（录入）
- 3. 销售方式：以租代售 / 以租代购（录入）
- 4. 填写客户、成交价、首付、押金、月供、期数（录入）

### 系统
- 5. 系统生成报单并锁定车辆（自动）
- 6. 判断：成交价低于指导价？（判断）
- 10. 报单状态：已激活（状态）
- 17. 合同状态：待出库（状态）
- 21. 车辆状态：以租代售（状态）
- 24. 全部期数还清后标记合同结清/待过户（判断）
- 27. 合同状态：已结清；车辆状态：已售（结束）

### 老板端
- 7. 老板端：审批中心 / 价格特批（低价）
- 28. 老板端：查看全过程记录（查看）

### 财务端
- 8. 财务端：审批中心 / 报单确认（查看）
- 9. 财务点击：确认报单（确认）
- 13. 财务端：审批中心 / 合同审批（确认）
- 16. 财务上传银行到账回单并点击通过（确认）
- 19. 财务端：确认合同、首付款、押金到账（确认）
- 23. 财务端：核对银行回单、流水号（核对）
- 26. 财务端：复核全部回款（复核）

### 运营端
- 11. 运营端：销售报单 / 转合同（点击）
- 12. 运营生成以租代售合同（发起）
- 14. 运营端：发起首付款及押金支付流程（发起）
- 15. 运营上传客户付款截图（上传）
- 18. 运营端：发起车辆出库（发起）
- 22. 运营端：每期发起还款对账（发起）
- 25. 运营端：确认尾款和费用全部结清（确认）

### 车管端
- 20. 车管上传出库照片、出库单照片并确认出库（确认）
