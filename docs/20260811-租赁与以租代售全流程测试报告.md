## 4. P0 修复与回归

### P0-01 底盘车报单门禁

- 修复：`create_sales_order` 查询车辆时带出 `box_type` / `vehicle_box_type`，非草稿报单对“底盘”直接返回 400，批量 VIN 同样逐辆校验。
- 回归：底盘 VIN 报单被拦截；普通厢货 VIN 仍可正常报单。
- 定位：`app.py:5018` 至 `app.py:5037`。

### P0-02 出库后客户还款计划激活

- 修复：`deliver_vehicle` 与合同、车辆状态更新处于同一事务时，将该合同 `period>=1` 的“未激活”账单更新为“待还款”。
- 回归：租赁与以租代售出库后均验证第 1 期为“待还款”，可进入回款核销。
- 定位：`app.py:9483` 至 `app.py:9490`；回款门禁见 `app.py:2106` 至 `app.py:2114`。
