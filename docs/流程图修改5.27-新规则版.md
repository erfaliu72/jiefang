# 流程图 5.27（按新规则调整版）

> 本版沿用 5.27 原框架：全局规则、租赁流程、以租代售流程、每期还款/催收/计划调整、租金减免、发票申请。
> 主要调整：新车由运营 Excel 导入并按车架号去重；指导价不再按整车价确认，以租代售核对首付款比例和每期还款比例，租赁核对押金比例和每期还款比例；财务确认报单不再上传车场/厂家分期表；首次付款不足增加老板审批、挂账应收、退款终止分支；每期少还不再顺延到下期，而是差额挂应收并按万5统计滞纳金。

# **一、全局规则**

```mermaid
flowchart TD
    A["运营端：上传新车 Excel 表格"] --> B["系统解析 Excel 车辆数据"]
    B --> C{"按车架号 VIN 与后台全部车辆比对"}
    C -- "VIN 已存在" --> D["判定为重复车辆<br/>不重复入库"]
    C -- "VIN 不存在" --> E["新增车辆资产<br/>车辆进入车库 / 状态：在库"]
    D --> F["导入结果汇总<br/>新增 / 重复 / 失败明细"]
    E --> F

    F --> G["销售端：新建销售报单"]
    G --> H{"销售端：选择业务模式"}
    H -- "租赁" --> I["进入租赁报单流程（见第二章）"]
    H -- "以租代售" --> J["进入以租代售报单流程（见第三章）"]

    K["老板端：维护租赁指导口径"] --> L["口径：押金比例 + 每期还款比例"]
    M["老板端：维护以租代售指导口径"] --> N["口径：首付款比例 + 每期还款比例"]

    K & M --> O["系统规则：指导价版本控制"]
    O --> P["存量订单（在租/在售）：适用签订时的老价格"]
    O --> Q["新增报单（新租售/新代售）：适用最新指导价"]

    R["系统规则：指导口径核对"] --> S["租赁报单：押金比例与每期还款比例核对"]
    R --> T["以租代售报单：首付款比例与每期还款比例核对"]
    R --> T1["不再对整车成交价进行指导价确认"]

    U["系统规则：报单驳回"] --> V["低于对应指导价且老板不通过"]
    V --> W["报单终止 / 返回销售端重新新建报单"]

    X["系统规则：财务确认报单"] --> Y["财务不再上传车场/厂家分期表"]
    X --> Z["财务不再做客户计划与车场计划价格比对"]
    X --> AA["财务确认后车辆锁定，进入合同与首次付款流程"]

    AB["系统规则：首次付款不足"] --> AC["销售上报实际付款金额、原因、剩余金额承诺归还时间"]
    AC --> AD["承诺期内不足部分只挂账应收，不记录万5滞纳金"]
    AD --> AE["老板审批是否允许不足额出库"]
    AE -- "同意" --> AF["车辆继续锁定，差额挂账为应收，允许出库"]
    AE -- "不同意" --> AG["老板发起退款，财务退款，本单结束"]

    AH["老板端：全过程查看"] --> AI["可查看导入、报单、比例口径、合同、付款、出库、还款、催款、扣款、退车、过户、盈利统计、车辆返利"]
    AH --> AJ["审批比例低于指导口径的价格特批、首次付款不足出库、退车等关键节点"]

    AK["财务端：新增车辆返利统计"] --> AL["记录车辆返利到公司报表（仅财务与老板可见）"]
```

# 二、租赁流程

### 2.1 报单 → 审批 → 出库

```mermaid
flowchart TD
    A["销售端：销售报单 / 新建报单"] --> B["选择车辆：在库车辆"]
    B --> C["销售方式：租赁"]
    C --> D["填写租赁报单数据<br/>客户、起租日、租期、押金、月租金、收款信息"]
    D --> E["系统生成租赁报价单"]
    E --> F["系统读取老板租赁指导口径（取最新版本）"]
    F --> G["系统核对押金比例与每期还款比例"]
    G --> H{"押金比例和每期还款比例<br/>是否均不低于老板指导口径？"}

    H -- "是：均不低于" --> I["财务端：确认租赁报单"]
    H -- "否：有一项低于" --> J["老板端：价格特批审批"]

    J --> K{"老板是否通过？"}
    K -- "驳回" --> L["报单终止 / 状态：已作废"]
    L --> A
    K -- "通过" --> I

    I --> M["系统按销售填写内容生成客户还款计划表<br/>仅生成客户侧计划"]
    M --> N["财务端：直接确认报单<br/>不上传车场/厂家分期表<br/>不做两张计划表价格比对"]
    N --> O["车辆锁定<br/>报单状态：已激活"]
    O --> P["线下合同签署完成"]
    P --> Q["运营端：上传线下合同 PDF"]
    Q --> R["运营端：发起首次付款<br/>租赁口径：押金 + 首期月租金"]
    R --> S["运营端：上传客户付款截图"]
    S --> T["财务端：上传公司收款清单<br/>核对实际到账"]
    T --> U{"首次付款是否足额？"}

    U -- "足额" --> V["财务确认首付款无误"]
    V --> W["合同状态：待出库"]

    U -- "不足额" --> X["销售在首期对账单上报实收金额<br/>备注不足原因和剩余金额承诺归还时间"]
    X --> Y["不足部分挂账为应收<br/>承诺期内不记录万5滞纳金"]
    Y --> Z["老板审批是否允许不足额出库"]
    Z -- "同意" --> AA["车辆继续锁定<br/>差额保留为应收，允许出库"]
    AA --> W
    Z -- "不同意" --> AB["老板发起退款"]
    AB --> AC["财务执行退款流程"]
    AC --> AD["本单结束<br/>报单/合同终止，车辆释放回在库"]

    W --> AE["车管端：车辆出库并上传出库照片 / 出库单"]
    AE --> AF["车辆状态：租赁中"]
```

### 2.2 还款周期 → 退车

```mermaid
flowchart TD
    Y["车辆状态：租赁中"] --> Z["进入每期还款与催收流程（见第四章）"]

    Z --> ZA{"还款周期结束方式"}

    ZA -- "客户申请提前退车 / 收车" --> AO["销售端：发起提前结束租车<br/>同时发起累计滞纳金是否收取/减免确认"]

    AH --> AI["车到公司后车管端：验车填单<br/>无问题确认回库，有维修需求改为待维修"]
    AI --> AJ["运营端：查询车辆相关数据并填单"]
    AJ --> AK["财务端：复核并退还剩余押金"]
    AK --> AL["车辆状态：在库 / 二手车 / 待维修"]
    AL --> AM["租赁流程结束"]

    AO --> AP["车管端：验车<br/>无问题确认回库，有维修需求改为待维修"]
    AP --> AQ["运营端：查询车辆相关数据并填单"]
    AQ --> AR["财务端：核对并扣减相应押金"]
    AR --> AS["车辆状态：在库 / 二手车 / 待维修"]
    AS --> AT["提前退车流程结束"]
```

# 四、每期还款、催收与计划表调整（租赁 / 以租代售共用）

说明：本章为租赁（第二章）和以租代售（第三章）在还款阶段共用的流程。系统每日自动执行，对所有未履约还款完成的车辆订单进行状态查询、催收和滞纳金累计记录。

### 4.1 每日监控与逾期催收

```mermaid
flowchart TD
    A["系统自动执行（每日）"] --> B["遍历所有未履约还款完成的车辆订单和挂账应收"]
    B --> C["读取还款计划表 / 挂账应收<br/>检查应还日期、应还金额、实收金额、到账状态"]
    C --> D{"当前距还款日或承诺归还日的时间节点"}

    D -- "首次付款不足挂账<br/>仍在承诺期内" --> E0["只展示待归还应收<br/>承诺期内不记录万5滞纳金"]
    D -- "首次付款不足挂账<br/>超过承诺归还日仍未归还" --> E1["转为逾期应收<br/>按剩余欠款记录万5滞纳金"]

    D -- "T-3（还款日前3天）" --> E["系统自动黄色预警"]
    E --> F["生成提醒文案<br/>尊敬的xx，您的车架号为xx的车辆将于xx日进行还款，请您知悉"]
    F --> G["标记订单状态：临近还款"]

    D -- "T 日（还款日当天）" --> H{"客户是否已还款？"}
    H -- "是" --> PAY["进入还款确认与计划表调整流程（见 4.2）"]
    H -- "否" --> N["标记订单状态：待催款"]

    D -- "T+3（逾期3天）" --> O["系统自动生成运营催款文案"]
    O --> P["运营上传催款单截图"]
    P --> Q["标记订单状态：T+3 运营已催款<br/>保留催款记录"]
    Q --> Q1{"客户是否已还款？"}
    Q1 -- "是" --> PAY
    Q1 -- "否" --> Q2["继续等待至 T+7"]

    D -- "T+7（逾期7天）" --> R["系统自动生成销售催款文案"]
    R --> S["销售上传催款记录 / 催款单截图"]
    S --> T["标记订单状态：T+7 销售已催款"]
    T --> T1{"客户是否已还款？"}
    T1 -- "是" --> PAY
    T1 -- "否" --> U["进入顺序扣款 / 风险处理记录"]
    U --> V["1. 保险 / 代办类费用"]
    V --> W["2. 维修 / 事故 / 罚金类费用"]
    W --> X["3. 本期租金及挂账应收"]
    X --> Y["4. 逾期滞纳金仅累计记录<br/>不自动收取"]
    Y --> Z["系统记录扣款明细、顺序、金额、时间、操作人"]
```

### **4.2 还款确认与计划表调整**

说明：当客户在任意时间点完成付款后（无论是否逾期），均进入本流程进行确认与计划表调整。多还款沿用原规则；少还款按本版新规则处理。

```mermaid
flowchart TD
    PA["销售/运营端：点击【本期还款】或【首期对账】<br/>上传客户支付截图并填写客户实付金额"] --> PB["财务端：上传公司收款清单 / 核销确认"]
    PB --> PC{"比对实际付款与标准应付金额"}

    PC -- "按标准付款" --> PD1["正常核销本期账单<br/>还款计划表不变"]

    PC -- "多于标准付款" --> PD3["沿用原多还款规则<br/>运营与客户确认抵扣月份<br/>系统更新后续还款计划表"]

    PC -- "少于标准付款" --> PD2{"少付发生在哪个阶段？"}

    PD2 -- "首次付款不足" --> PF1["销售在首期对账单上报实收金额<br/>备注不足原因和剩余金额承诺归还时间"]
    PF1 --> PF2["财务上传公司实际收款清单"]
    PF2 --> PF3["老板审批是否同意不足额出库"]
    PF3 -- "同意" --> PF4["实收金额入账<br/>差额挂账为应收<br/>承诺期内不记录万5滞纳金<br/>车辆可正常出库"]
    PF3 -- "不同意" --> PF5["老板发起退款"]
    PF5 --> PF6["财务执行退款流程"]
    PF6 --> PF7["本单结束<br/>报单/合同终止，车辆释放回在库"]

    PD2 -- "每期还款不足" --> PG1["实付金额记录为本期还款<br/>例：应还5000，实还4000，则4000记本期已收"]
    PG1 --> PG2["差额挂账为本期应收<br/>例：1000记录为应收"]
    PG2 --> PG3["差额按万5/日统计滞纳金<br/>滞纳金仅累计记录"]
    PG3 --> PG4["本车所有流程结束后<br/>由销售发起是否收取/减免滞纳金"]

    PD1 --> PE{"是否全部还清或租期到期？"}
    PD3 --> PE
    PF4 --> PE
    PG4 --> PE

    PE -- "否" --> PH["继续每日监控（回到 4.1）"]
    PE -- "是" --> PI["退出还款周期，回到主业务流程<br/>租赁→退车 / 以租代售→过户"]
```

### 4.3 租金减免 / 滞纳金收取确认流程

说明：在每期分期还款计划中可触发租金减免；本车流程结束时，由销售发起累计滞纳金是否收取或减免。

```mermaid
flowchart TD
    A["销售端：发起申请"] --> B{"申请类型"}
    B -- "租金减免" --> C["填写减免原因及金额"]
    B -- "滞纳金收取/减免确认" --> D["选择收取或减免<br/>填写累计滞纳金金额、原因和说明"]

    C --> E["老板端（领导）：审批"]
    D --> E
    E --> F{"是否通过？"}
    F -- "否" --> G["驳回申请"]
    F -- "是" --> H["财务端：复核通过"]
    H --> I{"执行结果"}
    I -- "租金减免" --> J["系统自动更新还款计划表<br/>减免金额在下一期付款中扣除"]
    I -- "滞纳金收取" --> K["生成或确认滞纳金应收<br/>进入收款对账"]
    I -- "滞纳金减免" --> L["冲减累计滞纳金记录<br/>保留审批与减免日志"]
```
