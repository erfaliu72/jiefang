# 金聚源车辆管理系统流程 Review 与测试报告

生成日期：2026-05-13

## 1. Review 结论

本次按最新业务要求复核当前系统流程，结论如下：

- 老板只在“成交价低于老板指导价”时进入审批链；高于或等于指导价的卖车、租车、以租代售流程不再经过老板审批。
- 老板端仍可查看报单、资产、审批、账单、对账、退车、利润、风险等过程记录和结果记录。
- 指导价已支持按时间点生效：老板修改车辆指导价后，后续新报单/新合同按新价判断；历史报单和历史合同保留原快照价格，不被回写。
- 法务端已取消，合同流程不再经过法务。
- 合同导出仅运营端和老板端可用，支持 Word/PDF。
- 当前自动化测试全通过，核心业务闭环可运行。

## 2. 当前审批流

| 流程类型 | 当前系统流程 | 老板是否参与 |
| --- | --- | --- |
| 价格特批 | 销售报单后系统判断，成交价低于指导价时进入老板审批 | 仅低于指导价时参与 |
| 合同审批 | 运营审核 -> 财务审核 | 不参与 |
| 首付款/押金支付 | 运营发起收款核对 -> 财务审核收款 | 不参与 |
| 车辆出库 | 运营/财务流程完成 -> 车管上传出库照片和出库单 -> 车管确认出库 | 不参与 |
| 每期还款对账 | 运营上传客户付款截图 -> 财务上传银行回单 -> 财务录入流水号核销 | 不参与 |
| 退车入库 | 销售发起 -> 车管验车填单 -> 运营查车辆数据 -> 财务复核 -> 车管入库 | 不参与 |
| 锁车 | 销售发起 -> 财务审核 -> 系统锁车 | 不参与 |

## 3. 三类业务流程复核

### 卖车

```text
销售新建报单
-> 系统判断成交价与指导价
-> 低于指导价：老板价格特批；不低于指导价：跳过老板
-> 财务确认报单到账
-> 销售转合同
-> 运营发起合同审批
-> 财务审核合同
-> 运营发起首付款/押金支付
-> 财务上传回单并审核收款
-> 车管上传出库照片和出库单
-> 车管确认出库
-> 车辆状态变为“已售”，销售合同结清
```

## 4. 指导价规则 Review

实现方式：

- 车辆表保存当前指导价。
- 老板每次修改指导价时，系统写入 `vehicle_guidance_price_history`，记录旧价格、新价格、修改人、生效时间。
- 销售报单创建时，系统读取当时车辆指导价并写入 `sales_orders.snapshot_guidance_price`。
- 合同创建时，系统读取当时车辆指导价并写入 `contracts.snapshot_guidance_price`。
- 后续老板再改指导价，不会修改历史报单和历史合同快照。

判断规则：

- 指导价为空或为 0：不触发老板价格特批。
- 成交价低于指导价：报单状态为“待老板价格审批”，生成 `price_exception` 审批。
- 成交价高于或等于指导价：报单直接进入“待财务确认”。
- 老板价格特批通过后，报单进入“待财务确认”。
- 老板价格特批驳回后，报单进入“价格特批驳回”，不能继续财务确认。

## 5. 权限 Review

| 角色 | 当前关键权限 |
| --- | --- |
| 老板 | 查看全流程记录，维护指导价，处理低于指导价的价格特批，导出合同 |
| 销售 | 新建报单，转合同，发起退车，发起锁车 |
| 运营 | 发起合同审批，发起首付款/押金审核，上传客户还款截图，导入厂家还款计划，新增费用项 |
| 财务 | 确认报单到账，审核合同，上传收款/银行回单，核销客户还款，确认厂家还款，复核退车 |
| 车管 | 新车入库，上传出库资料，确认出库，退车验车填单，旧车入库 |

注意事项：

- 老板账号仍是系统超级管理员，部分底层接口保留超管能力。
- 但审批通过/驳回接口已按审批节点角色限制，老板不能代替运营、财务、车管处理普通审批节点。
- 前端普通流程按钮已按业务角色收敛，老板主要用于查看和价格特批。

## 7. 仍需关注的风险

- 老板账号仍是超级管理员，适合内部演示和管理，但若未来要严格做到“老板只能看，不能操作普通流程接口”，需要进一步拆分“老板”和“系统管理员”两个角色。
- 退车流程当前已实现主链路，但“销售发起退车”和“车管验车填单”在界面上仍共用退车验收单入口，后续可优化成分步向导。
- 指导价判断目前使用报单的 `sale_total_price`，如果业务上租车/以租代售要用“首付款 + 押金 + 总租金”或其他口径判断，需要再明确价格口径。
- 旧版 `xls` 还款计划仍建议转换为 `xlsx` 后导入。
- 合同模板字段已支持自动填充导出，正式签署前仍建议运营复核 Word 内容。
