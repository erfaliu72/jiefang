# 经营租赁与以租代售工作流

说明：本文档为可编辑版本。每个流程使用 Mermaid 语法编写，可以直接修改节点文字、箭头方向、判断条件，也可以复制到 Mermaid Live Editor、draw.io、飞书文档、语雀等支持 Mermaid 的工具中渲染成流程图。

## 全局规则

```mermaid
flowchart TD
    A["车管端：车辆入库"] --> B["车辆进入车库 / 状态：在库"]
    B --> C["销售端：新建销售报单"]
    C --> D{"销售端：选择业务模式"}
    D -- "租赁" --> E["进入租赁报单流程"]
    D -- "以租代售" --> F["进入以租代售报单流程"]

    G["老板端：维护租赁指导价"] --> H["口径：租赁每期分期指导价"]
    I["老板端：维护整车指导价"] --> J["口径：以租代售整车指导价"]

    G & I --> V1["系统规则：指导价版本控制"]
    V1 --> V2["存量订单（在租/在售）：适用签订时的老价格"]
    V1 --> V3["新增报单（新租售/新代售）：适用最新指导价"]

    K["系统规则：价格核对"] --> L["租赁报单：报价与租赁每期分期指导价核对"]
    K --> M["以租代售报单：报价与整车指导价核对"]

    N["系统规则：报单驳回"] --> O["低于对应指导价且老板不通过"]
    O --> P["报单终止 / 返回销售端重新新建报单"]

    Q["老板端：全过程查看"] --> R["可查看报单、报价、合同、客户还款计划表、车队还款计划表、付款、出库、还款、催款、扣款、退车、过户、盈利统计"]
    Q --> S["只审批低于对应指导价的价格特批"]
```

## 租赁流程

```mermaid
flowchart TD
    A["销售端：销售报单 / 新建报单"] --> B["选择车辆：在库车辆"]
    B --> C["销售方式：租赁"]
    C --> D["填写租赁报单数据<br/>客户、起租日、租期、押金、月租金、收款信息"]
    D --> E["系统生成租赁报价单"]
    E --> F["系统读取租赁每期分期指导价"]
    F --> G["系统核对租赁报价与租赁指导价"]
    G --> H{"租赁报价是否低于指导价？"}

    H -- "否" --> I["财务端：审批租赁报单"]
    H -- "是" --> J["老板端：价格特批审批"]

    J --> K{"老板是否通过？"}
    K -- "驳回" --> L["报单终止 / 状态：价格特批驳回"]
    L --> A
    K -- "通过" --> I

    I --> M["系统按销售填写内容自动生成客户还款计划表"]
    M --> N["财务端：上传解放给车队的还款计划表"]
    N --> O["系统比对两张还款计划表"]
    O --> P["财务端：确认报单并复核两张还款计划表"]
    P --> Q["系统生成单车盈利统计基础数据"]
    Q --> R["财务端：统计车辆盈利情况"]
    R --> S["销售端：线下签署合同"]
    S --> T["运营端：上传合同 PDF"]
    T --> U["客户支付：押金 + 首期月租金"]
    U --> V["运营端：上传客户付款截图"]
    V --> W["财务端：上传公司首款银行流水号"]
    W --> X["车管端：车辆出库并上传出库照片"]
    X --> Y["车辆状态：租赁中"]

    Y --> Z0["系统自动每日查询：所有未履约还款完成的车辆订单状态"]
    Z0 --> Z["系统读取该订单客户还款计划表"]
    Z --> AA["系统自动核对每期应还日期、应还金额、实收金额、到账状态"]
    AA --> AB["T-3：系统自动黄色预警"]
    AB --> AC["系统自动生成催款文案<br/>尊敬的xx，您的车架号为xx的车辆将于xx日进行还款，请您知悉"]
    AC --> AD["客户支付当期款项"]
    AD --> AE["运营端：点击【本期还款】按钮并上传客户支付截图"]
    AE --> AF["财务端：上传公司收款截图 / 核销确认"]
    AF --> AG{"比对实际还款与标准还款金额"}

    AG -- "按标准还款" --> AH1["正常核销本期账单"]
    AG -- "少于标准还款" --> AH2["差额顺延，下期还款计划增加相应差额"]
    AG -- "多于标准还款" --> AH3["运营与客户确认抵扣月份，调整后续还款"]
    
    AH1 & AH2 & AH3 --> AI1["系统重新调整并更新还款计划表"]
    AI1 --> AJ1{"是否还有未还期数且未全部还清？"}

    AJ1 -- "有" --> Z0
    AJ1 -- "无 / 全部还清 / 租期结束" --> AH["销售端：发起退车"]

    AH --> AI["车到公司后车管端：验车填单"]
    AI --> AJ["运营端：查询车辆相关数据并填单"]
    AJ --> AK["财务端：复核并退还剩余押金"]
    AK --> AL["车管端：确认入库"]
    AL --> AM["车辆状态：在库 / 二手车"]
    AM --> AN["租赁流程结束"]

    AO["提前结束租车"] --> AP["运营端：发起提前结束租车"]
    AP --> AQ["车管端：验车"]
    AQ --> AR["财务端：核对并扣减相应押金"]
    AR --> AS["车管端：确认回库"]
```

## 以租代售流程

```mermaid
flowchart TD
    A["销售端：销售报单 / 新建报单"] --> B["选择车辆：在库车辆"]
    B --> C["销售方式：以租代售"]
    C --> D["填写以租代售报单数据<br/>客户、起租日、分期、首付款、月租金"]
    D --> E["系统生成以租代售报价单"]
    E --> F["系统读取整车指导价"]
    F --> G["系统核对以租代售报价与整车指导价"]
    G --> H{"整车报价是否低于指导价？"}

    H -- "否" --> I["财务端：审批以租代售报单"]
    H -- "是" --> J["老板端：价格特批审批"]

    J --> K{"老板是否通过？"}
    K -- "驳回" --> L["报单终止 / 状态：价格特批驳回"]
    L --> A
    K -- "通过" --> I

    I --> M["系统按销售填写内容自动生成客户还款计划表"]
    M --> N["财务端：上传解放给车队的还款计划表"]
    N --> O["系统比对两张还款计划表"]
    O --> P["财务端：确认报单并复核两张还款计划表"]
    P --> Q["系统生成单车盈利统计基础数据"]
    Q --> R["财务端：统计车辆盈利情况"]
    R --> S["销售端：线下签署合同"]
    S --> T["运营端：上传合同 PDF"]
    T --> U["客户支付：首付款"]
    U --> V["运营端：上传客户付款截图"]
    V --> W["财务端：上传公司首款银行流水号"]
    W --> X["车管端：车辆出库并上传出库照片"]
    X --> Y["车辆状态：以租代售"]

    Y --> Z0["系统自动每日查询：所有未履约还款完成的车辆订单状态"]
    Z0 --> Z["系统读取该订单客户还款计划表"]
    Z --> AA["按销售填写的分期自动生成每期应还任务"]
    AA --> AB["次月开始还款"]
    AB --> AC["系统自动核对每期应还日期、应还金额、实收金额、到账状态"]
    AC --> AD["T-3：系统自动黄色预警"]
    AD --> AE["系统自动生成催款文案<br/>尊敬的xx，您的车架号为xx的车辆将于xx日进行还款，请您知悉"]
    AE --> AF["客户支付当期款项"]
    AF --> AG["运营端：点击【本期还款】按钮并上传客户支付截图"]
    AG --> AH["财务端：上传公司收款截图 / 核销确认"]
    AH --> AI1{"比对实际还款与标准还款金额"}

    AI1 -- "按标准还款" --> AJ1["正常核销本期账单"]
    AI1 -- "少于标准还款" --> AJ2["差额顺延，下期还款计划增加相应差额"]
    AI1 -- "多于标准还款" --> AJ3["运营与客户确认抵扣月份，调整后续还款"]
    
    AJ1 & AJ2 & AJ3 --> AK1["系统重新调整并更新还款计划表"]
    AK1 --> AL1{"是否全部期数及金额均已还清？"}

    AL1 -- "否" --> Z0
    AL1 -- "是" --> AJ["财务端：复核全部回款结清"]
    AJ --> AK["进入过户流程"]
    AK --> AL["车辆过户至客户名下"]
    AL --> AM["车辆状态：已售 / 已过户"]
    AM --> AN["以租代售流程结束"]
```

## 还款提醒、逾期催款与顺序扣款

```mermaid
flowchart TD
    A["系统自动执行（每日）"] --> A1["查询所有未履约还款完成的车辆订单状态"]
    A1 --> B["系统读取还款计划表"]
    B --> C["系统检查每个订单的应还日期、应还金额、实收金额、到账状态"]
    C --> D{"判断当前处于哪个还款节点"}

    D -- "T-3" --> E["系统自动黄色预警"]
    D -- "T" --> F["系统检查当日是否已还款"]
    D -- "T+3" --> G["运营催款节点"]
    D -- "T+7" --> H["销售催款节点"]

    E --> I["系统自动生成提醒文案"]
    I --> J["示例：尊敬的xx，您的车架号为xx的车辆将于xx日进行还款，请您知悉"]
    J --> K["标记订单状态：临近还款"]

    F --> L{"当日是否已到账？"}
    L -- "是" --> M["标记订单状态：已还款"]
    L -- "否" --> N["标记订单状态：待催款"]

    G --> O["系统自动生成运营催款文案"]
    O --> P["运营上传催款单截图"]
    P --> Q["标记订单状态：T+3 运营已催款"]

    H --> R["系统自动生成销售催款文案"]
    R --> S["销售上传催款记录 / 催款单截图"]
    S --> T["标记订单状态：T+7 销售已催款"]
    T --> U["进入顺序扣款"]
    U --> V["1. 保险 / 代办类费用"]
    V --> W["2. 维修 / 事故 / 罚金类费用"]
    W --> X["3. 逾期滞纳金"]
    X --> Y["4. 本期租金"]
    Y --> Z["系统记录扣款明细、顺序、金额、时间、操作人"]
```
